# Privacy policy: gmail-mcp

gmail-mcp is a personal application used only by its owner, Jonny Mearns (jonny.mearns@gmail.com).

- It accesses the owner's own Gmail account to read messages and to create drafts for the owner's review. It does not send email.
- Data is processed only on the owner's private server and is not sold, shared or disclosed to anyone.
- Access can be revoked at any time at <https://myaccount.google.com/permissions>.

Contact: jonny.mearns@gmail.com
